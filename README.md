# Basics of Python

A beginner-friendly collection of **Python basics** explained through **Jupyter Notebooks**. This repository is intended for learners who want clear examples and hands-on practice with core Python concepts.


## Contents

This repo contains Jupyter Notebooks covering fundamental topics such as:

- Python syntax and variables
- Data types (int, float, string, boolean)
- Operators
- Conditional statements (`if/elif/else`)
- Loops (`for`, `while`)
- Functions
- Lists, tuples, sets, and dictionaries
- Basic input/output
- Common built-in functions
- Practice problems / examples (if included)

> Tip: If you want, rename notebooks with numeric prefixes (e.g., `01_variables.ipynb`, `02_conditions.ipynb`) to make the learning path obvious.

## Getting Started

### Option 1: Run on Google Colab (Recommended)
1. Open this repository on GitHub.
2. Open any `.ipynb` notebook file.
3. Copy the notebook URL and paste it into: https://colab.research.google.com/
4. Run the cells top-to-bottom.

### Option 2: Run Locally

#### Prerequisites
- Python 3.8+ (recommended)
- Jupyter Notebook or JupyterLab

#### Setup
```bash
# (optional) create and activate a virtual environment
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

# install jupyter
pip install jupyter
```

#### Launch Jupyter
```bash
jupyter notebook
```
Then open any notebook in your browser.
